# DropVault: Smart Autonomous Delivery Locker

An IoT smart locker built around a Raspberry Pi 5 (in progress).

> Status: under active development. The features below describe the design; update the Status section as parts are completed.

## Features (design targets)

- Temperature-controlled compartments
- Weight sensing to confirm a parcel has been placed or removed
- Servo-controlled locks
- Computer-vision delivery authentication using an IR camera
- Audio-guided instructions after successful verification

## Tech stack

- Raspberry Pi 5
- Python
- OpenCV
- Weight sensors, temperature sensing, servo motors, IR camera
